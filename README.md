# 오션짐 업무 체크리스트

시간대별 헬스장 업무를 등록하고, 직원들이 각자 폰에서 체크할 수 있는 웹앱입니다.

## 구조
- `index.html` — 직원용 화면 (로그인 없이 누구나 접근, 체크만 가능)
- `admin.html` — 관리자용 화면 (아이디+PIN 로그인 후 시간대/업무 추가·삭제·순서 변경, 완료 기록 조회)
- `netlify/functions/tasks.js` — 업무 목록 조회/저장 (저장은 관리자 인증 필요)
- `netlify/functions/checks.js` — 오늘 날짜 기준 체크 상태 조회/저장 (날짜별로 자동 분리되어 매일 자정 자동 초기화됨)
- `netlify/functions/history.js` — 날짜별 체크 기록 조회 (관리자 인증 필요, 최근 N일치)

## 최초 설정 (필수)
Netlify 사이트 설정 → Environment variables 에서 아래 두 값을 등록해야 관리자 로그인이 됩니다.

- `ADMIN_ID` — 관리자 아이디 (예: gymadmin)
- `ADMIN_PIN` — 관리자 PIN 4자리 (예: 1234)

## 로컬에서 테스트하기
```
npm install
netlify link      # 최초 1회, 연결할 Netlify 사이트 선택
netlify dev
```
`netlify dev`를 실행하면 로컬에서 함수(Functions)까지 포함해 실제 배포와 동일하게 동작을 확인할 수 있습니다. 관리자 로그인을 테스트하려면 로컬 환경에도 `ADMIN_ID`, `ADMIN_PIN` 환경변수가 필요합니다 (`netlify link` 이후 `netlify env:pull`로 가져오거나, `.env` 파일에 직접 추가하세요).

## 참고
- 체크 상태는 항목별로 독립된 키(`checks:YYYY-MM-DD:taskId`)로 저장됩니다. 여러 항목을 동시에 체크해도 서로 덮어쓰지 않도록 하기 위한 구조이며, 날짜별로 자동 분리되어 별도 초기화 작업 없이 매일 자정(KST) 기준 자동으로 새 목록이 됩니다.
- **주의**: 이 구조는 2026.09.09-10 버전부터 적용됐습니다. 그 이전 버전으로 저장된 과거 체크 기록(날짜 하나에 통째로 저장된 옛 형식)은 새 버전에서는 조회되지 않습니다(완료 기록 히스토리에서 그 이전 날짜는 빈 것처럼 보일 수 있음).
- 직원 화면은 15초마다 체크 상태와 업무 목록을 자동 새로고침해 다른 직원이 체크한 내용, 관리자가 새로 추가한 업무 모두 함께 반영됩니다.
- 직원 화면 우측 하단의 작은 "관리자" 링크로 관리 화면에 진입할 수 있습니다.
- 완료 기록은 **현재 등록된 업무 목록 기준**으로 통계를 계산합니다. 과거에 있었지만 지금은 삭제된 업무의 체크 기록은 통계에 포함되지 않습니다.
